Methodology

After-hours = calls outside office hours.
Overflow = calls arriving when all staff lines were busy. Counted by checking how many calls were already in progress at each call's start time.
Human counterfactual = what if every call took as long as a human-handled call? We measure real human call durations from transferred calls (time from transfer pickup to call end). Since AI already pre-screened those calls, actual human-from-scratch durations would be even longer — making this a conservative estimate. With longer calls, more lines stay busy longer, causing more overlap → more overflow.
